# Sahtek

Ein kleines, elegantes deutsches Portfolio-Projekt zur Schätzung des täglichen Kalorienbedarfs.

## Start
Öffne `index.html` direkt im Browser.

## Technologie
- HTML5
- CSS3
- Vanilla JavaScript
- Responsive Design

## Berechnung
Die Seite verwendet die Mifflin-St-Jeor-Gleichung für den geschätzten Ruheenergieverbrauch und ergänzt Aktivität, Arbeit und Sport als Planungsfaktoren.

Hinweis: Das Ergebnis ist eine Schätzung und kein medizinischer Rat.
